# 上游渠道同步管理

后台「模型与资源 → 渠道同步」为每个系统渠道保存独立同步配置。定时任务由后端 Worker 执行，不依赖管理员保持登录或浏览器打开。时区固定为 `Asia/Shanghai`，每天 00:00 到期，Worker 每 15 秒领取到期任务；服务停止期间错过的任务在恢复后补执行一次。

## 同步脚本

目前提供两个受管脚本适配器，管理端选择脚本并编辑其配置，不执行上传的 Shell 或任意命令：

- **授权目录监控**：使用渠道已保存的凭证读取 OpenAI 格式的 `/v1/models`，核对型号授权。适合免费渠道或上游未提供公开价格目录的情况。
- **模型广场价格同步**：同时读取授权目录和 HTTPS 公开 `model-plaza` JSON，按管理员选择的分组 ID 匹配上游 SKU、图片质量或视频清晰度。可同步非空简介，以及已配置且启用价格档的成本和售价。

配置中可选择是否导入新型号，导入时保持停用、不推断能力或接口协议。已有手动停用的模型也不会自动启用。授权目录中已移除的启用模型会停用；已合并进模型家族的上游 SKU 不重复导入。停用或删除的渠道不领取定时任务。

成本以每积分 1,000,000 微积分精确转换。售价按该价格档原成本／售价比例计算并向上取整，因此原来的毛利比例或加价比例分别保留，不统一改为同一个利润值。零成本变为收费、分组倍率变化、动态计费、计费单位变化、报价歧义、精度超限等情况需人工复核，本次不提交任何模型变更。上游未提供报价的 SKU 保留原价并记入警告。

## 管理操作与执行记录

- 保存配置后，启用的任务从下一个北京时间零点开始执行；暂停会清除下一次自动执行时间，仍可手动「立即同步」。
- 「立即同步」异步返回执行记录，页面轮询展示执行中、成功或失败；记录保留授权数量、新增／停用型号、更新价格档与简介数量，以及警告或失败原因。
- 单次同步最多执行 3 分钟，数据库领取租约为 5 分钟。手动与定时领取同一渠道互斥，多实例不会重复领取；执行时不能修改配置。
- 模型变更与成功记录在同一事务提交，校验渠道、模型和价格档的版本与更新时间；管理员并发修改时整批回滚。
- 过期租约会被恢复并标记中断；未完成的定时任务重新入队，成功任务不会因重启再执行。未知供应商错误不保存原始 URL、密钥或响应正文。

## 从宿主机 QT 定时器切换

启用后台管理的 QT 同步后，应停用旧的 `open-ai-canvas-qt-sync.timer`，避免两个机制同时改价。新的 Worker 按现有价格比例定价，不再强制使用旧脚本的 120% 成本加价规则，也不会自动启用经过人工停用的型号。

```bash
sudo systemctl disable --now open-ai-canvas-qt-sync.timer
```

旧脚本仍可人工检查，但不要与后台任务并发执行。公开价格目录失效时，在执行记录中处理失败原因；不能改用生成请求探测模型，避免产生收费。
