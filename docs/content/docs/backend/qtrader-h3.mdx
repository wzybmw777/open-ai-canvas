# QT H3 渠道接入

仅接入 `https://api.qtrader.cc` 授权目录中的 `h3-video`，不导入同密钥下的图片模型。
模型展示名（一级目录）统一为 **MiniMax H3**，标识使用内置 `Minimax` Logo。

| 渠道展示名（二级目录） | 分辨率 | 时长 | 画幅 |
| --- | --- | --- | --- |
| QT H3渠道 · 长视频 | 480p / 720p / 768p | 4–30 秒 | 16:9、9:16 |
| QT H3渠道 · 高清 | 960p / 1080p | 4–15 秒 | 16:9、9:16、21:9、4:3、1:1、3:4 |

两个本地选项均调用同一个上游 `h3-video`，分别配置能力与价格档，避免高清选项提交超过 15 秒。
默认 6 秒，默认分辨率分别为 768p、1080p。长视频统一保留横竖屏，避免 720p 画幅限制与
768p 21:9 最长 20 秒限制产生不合法组合；这些限制也在协议插件中校验。
标签为文生视频、9图参考、对应分辨率、时长与按秒计费。
两档简介仅描述各自支持的分辨率与时长；定时同步保留共用上游型号的本地非空简介。

## 请求与参考素材

`plugin-packages/qtrader-h3/` 为独立声明式插件，创建使用 `POST /v1/videos` multipart，
发送 `model`、`prompt`、`seconds` 和像素 `size`；多张图片按输入顺序重复上传 `input_reference`。
支持文生、图生和多图参考，最多 9 图，每张最多 24 MiB，提示词最多 12000 字符。
保持上游默认音频输出，关闭额外收费的提示词优化。

依据 [SparkCine 开发文档](https://hi.hi.run/developers)，音频和视频引用属于原生 H3 入口的能力；
当前 QT OpenAI 兼容入口只声明参考图，因此不开放音频、视频引用或首尾帧模式。
首尾帧使用另一个 `h3-video-frames` 型号，本次不接入。
查询与下载沿用 `/v1/videos/{id}` 和 `/v1/videos/{id}/content`；优先使用返回的临时下载链接，
生成完成后由影策保存结果。未声明取消接口。

## 成本、售价与同步

报价来自 QT 公开 `model-plaza` 的 `sparkcine-h3组`（ID 100），与该密钥的授权目录交叉核对。
每元转换为 1,000,000 微积分，初始售价沿用本站成本加价 25%。

| 分辨率 | 初始成本（微积分/秒） | 初始售价（微积分/秒） |
| --- | --- | --- |
| 480p / 720p / 768p | 15000 | 18750 |
| 960p | 120000 | 150000 |
| 1080p | 160000 | 200000 |

以上为接入时核对值，运行时以有效价格档为准。[SparkCine 价格页](https://hi.hi.run/w/my-studio-cf76354141/pricing)
展示的是公共零售价，不能覆盖 QT 分组的专属报价。该页另有单次最低费用说明，QT 分组没有
最低扣费字段；真实上游账单是否另收最低费用仍需核对。

`scripts/sync-qtrader-h3.mjs` 负责首次安装插件、创建渠道和两个模型选项、配置后台每 30 分钟同步，
也可触发现有后台同步。通过管理员 HTTP API 写入，凭证由后端加密保存，不直接修改数据库。

```bash
# 默认只读取公开目录并输出不含密钥的配置计划。
node scripts/sync-qtrader-h3.mjs --dry-run

# 在终端安全输入；值只放在当前进程环境，不写进命令历史或文件。
export CANVAS_ADMIN_BASE_URL=https://your-canvas.example
read -rs -p '管理员会话值: ' CANVAS_ADMIN_COOKIE; echo
export CANVAS_ADMIN_COOKIE
read -rs -p 'QT H3 API Key: ' QTRADER_H3_API_KEY; echo
export QTRADER_H3_API_KEY
node scripts/sync-qtrader-h3.mjs --apply
unset QTRADER_H3_API_KEY

# 已接入后只触发后台同步，不重新安装或覆盖能力、展示和利润比例。
node scripts/sync-qtrader-h3.mjs --sync
unset CANVAS_ADMIN_COOKIE
```

首次写入前备份数据库和插件注册表。需要 Node.js 20 以上与 zip；管理员会话值仅填
`open_ai_canvas_session` Cookie 的值。已有同名渠道时拒绝重复初始化，中途配置失败会停用新渠道。
脚本不打印凭证、服务端原始错误正文或渠道密文。

后台选择现有“模型广场价格同步”脚本，固定分组 100，启用价格同步、关闭导入新型号。
Worker 每 30 分钟在北京时间整点和半点执行，保留每档现有成本/售价比例，不覆盖手工停用、能力、标签或 Logo；
手工和定时运行通过现有渠道租约互斥。执行状态可在后台“渠道同步”查看。
`--sync` 返回已领取的运行 ID，实际成功须以后台完成记录为准。
无需额外 systemd 定时器或服务重启。授权、价格分组或报价歧义时拒绝推断。

专项验证：`node --test scripts/sync-qtrader-h3.test.mjs`，
后端 `go test ./internal/protocol -run TestQtraderH3 -count=1`。
真实生成、9 图上传、最低扣费与输出音轨仍需实际任务验收。
