# 功能清单

## 项目创作入口

图片和视频工作台支持通过 `?project=<画布 ID>` 进入，未指定时自动准备并选择默认画布项目。记录按画布项目筛选，切换项目会清空当前草稿与参考素材。任务已提交但详情读取失败时会提示刷新记录，避免误导用户重复提交。

手机工作台优先展示提示词输入，推荐工具通过选择入口展开；设置页模型名称、价格和素材详情统一使用可读字号，导航在桌面与手机分别采用纵向和横向布局。

用户工作台以「开始创作、我的项目、素材库、作品与发布」为主要导航，灵感库与独立生成工具位于「创作工具」分组。「我的项目」（`/projects`）直接展示画布项目，点击卡片打开 `/canvas/:id`；原短剧制作总览、章节和制作阶段页面已从用户路由移除。

登录后进入「开始创作」会自动准备并选中真实画布「默认项目」，无需手工创建短剧制作项目。选择器显示画布项目，「打开项目」进入「我的项目」列表；文本、图片、视频任务使用选中画布的 ID，转入画布时将对话合并到同一画布，Agent 也进入该画布。已有消息的对话固定画布项目，新建创作可重新选择；没有画布关联的历史对话仍可查看。初始化和保存失败时显示重试入口，不以本地缓存替代云端保存成功；游客仍可编辑提示词，提交时要求登录。对话记录按账号保存在浏览器中，任务与生成素材由服务端持久化。

历史用户消息的复制按钮仍将可见提示词写入剪贴板，同时把原提示词、参考素材和模型设置恢复到当前输入框；铅笔编辑入口使用同一份草稿恢复逻辑。没有可用项目时，只复制文字，不填入输入框。

创作参考素材统一按当前模型的媒体能力校验，本地缓存、远端分页和插件素材使用相同的参考图片、视频、音频限制；切换模型后重新计算可选状态，确认添加时再次检查能力与数量。

OpenAI Images 的旧渠道配置若缺少像素预设，会按线路声明的比例与 1K/2K/4K 质量档位补齐已知尺寸映射；生成前按所选档位换算成上游要求的像素尺寸，其他声明式图片协议仍按各自能力合同校验。

文本的流式与思考开关归入「高级设置」，媒体规格和服务端报价沿用现有能力。作品页提供紧凑页头、统一发布入口，以及全部作品/我的作品和内容类型筛选。

项目列表支持按名称搜索、排序、新建、重命名、导入导出和删除画布。新建只需填写画布名称，不再要求创建或选择短剧制作项目；已有画布及其内容保持。独立图片和视频工作台同样使用画布项目，服务端验证画布归属；有关联的旧业务项目已归档时仍拒绝生成。

## AI 去水印

工作台侧栏提供统一的“AI 去水印”入口 `/toolbox/watermark`，图片和视频在同一页面通过页签切换。管理员在「功能开放」开启「AI 去水印」（默认关闭），且任一图片/视频工作台开放时显示入口，对应页签仍需各自工作台开启。关闭去水印后阻止页面访问、任务提交及历史去水印任务重试，已有任务继续执行，历史与结果保留。切换页签保留各自上传内容、选区和任务状态，图片与视频任务分别通过 `imageTask` / `videoTask` 查询参数恢复。

图片支持平台图片编辑模型、自动/蒙版修复、前后对比、下载、素材保存和历史。视频支持平台 `video_edit` 模型、文字要求、原视频与结果播放、下载和失败恢复，接受 3–15 秒、100 MiB 内的 MP4/MOV。沿用平台模型、任务、积分和资源，不需要独立推理服务。当前代码已实现，部署与效果验收待完成。详见 [图片去水印](/docs/backend/image-watermark-removal)与[视频去水印](/docs/backend/video-watermark-removal)。

## 画布多窗口实时协作

同一账号在多个窗口打开同一画布时，在画布顶部正中间以紧凑入口显示在线设备数量，展开后查看“设备1、设备2”等会话。服务端统一编号，各窗口名称和颜色一致，自己所在行标记“此窗口”。只显示远端光标的小标签和轻量拖拽轮廓；只剩一个窗口时全部隐藏并停止采集光标。高频坐标按帧直接更新独立浮层，不触发 React 重渲染。WebSocket 广播临时预览和提交后的同步通知，最终内容仍经过原有 operations 保存与并发合并；正常空闲连接改为低频状态校验，断线保留轮询。未配置 Redis 支持单后端进程，配置后支持跨实例分发；不增加跨账号编辑权限。真实浏览器与部署验收见[待测试](/docs/progress/pending-test)，协议见[画布操作同步](/docs/backend/canvas-operations-sync)。

## 用户登录日志

管理员在“用户与运营 → 用户登录日志”查看密码、邮箱/短信验证码、Linux.do 的成功/失败登录、注册自动登录和主动退出。支持用户、事件、方式、结果、IP、时间范围筛选、分页、刷新、详情和失败重试；显示账号快照、设备信息和安全原因。成功记录与会话操作原子提交，重复/伪造/过期退出不产生成功事件；刷新和自然过期不计为登录/主动退出。普通用户不可访问，不记录密码或会话凭据，不补造历史。

## 个人信息

“更换头像”弹窗集中提供上传图片和系统头像两种方式。头像上传支持固定 1:1 裁剪：拖动裁剪框、调整大小、键盘移动和重置，确认裁剪后返回弹窗预览，在弹窗内保存。系统头像提供默认人像、导演、摄影师、小猫、小兔、机器人、探索者和灵感 8 款，在同一弹窗内选择并保存；保存后全局同步，刷新保持。

“账户与设置”新增“个人信息”，展示账号名称与绑定邮箱状态。用户可预览并保存个人头像或恢复系统默认头像，顶栏、侧栏、账户卡片与创作消息同步更新。密码修改与邮箱更换分别保存；修改密码需要当前密码，邮箱更换还需要新邮箱验证码，成功后退出所有登录会话。纯 Linux.do 账号可重新授权核验身份后设置本地密码或更换邮箱。沿用现有设置页、表单、按钮反馈与主题，未增加昵称、用户名或角色编辑。

## 生图与视频工作台

普通用户可分别使用生图、视频工作台。通过工具卡片选择场景，套用预设提示词，按所选模型能力配置参数和参考素材；生成结果、运行任务及历史详情在同一页面查看。管理员在「工作台工具」维护分类、图标/封面、预设、使用说明与示例素材，并在「功能开放」分别控制两个入口。新入口默认关闭；工作台任务经过统一任务与计费服务创建。

详见[生图与视频工作台](./workbench)。

## 百炼 MiniMax 视频

`dashscope-minimax-video` 独立插件接入百炼 `MiniMax/MiniMax-H3`，支持文生视频、首帧、仅尾帧、首尾帧与图像/视频/音频多模态参考。插件校验 4–15 秒、768P/2K、7000 字符提示词及媒体角色和数量，模型能力由渠道配置。任务经统一宿主鉴权、轮询与结果持久化，恢复时查询原任务；真实文生视频创建、轮询与下载已验证，多模态及应用内完整链路仍待验收。配置见[百炼 MiniMax 视频](/docs/backend/bailian-minimax-video)。

## 图片预览与创作首页

受管图片在后台生成等比例缩略图，项目封面、素材预览和画布轻量视图优先加载小图；高清预览、下载与模型输入继续使用原件。支持 JPEG、PNG、GIF 首帧及 WebP，保留透明度并校正 JPEG 照片方向；尚未生成时展示原图或加载占位。

素材库图片详情复用统一资源授权与缓存，打开时立即加载原图，并在等待期间复用卡片缩略图。原图失败可手动重试；切换素材时重置缩放与拖动位置。

创作首页先用打包的本地精选图显示中心灵感，再在空闲时补充外部画廊并懒加载相邻和侧翼图片；用户开始输入后停止补充图库请求。首页画廊池每种创作类型最多保留 48 条，避免把完整提示词目录下载到首屏。轮播通过拖动、触屏滑动或滚轮切换，不显示左右按钮；键盘聚焦后可用方向键切换、回车使用创意。手机端收紧画廊、输入区与工具栏，夜间次要文案使用统一可读颜色。

首次访问默认使用夜间模式，已有主题偏好继续保留。创作对话用户气泡使用中性表面和细边框，夜间为石墨灰、浅色为浅灰，避免长文本区域混入强调色和外发光。

## 邮箱与手机号登录注册

后台「登录与注册」支持配置邮箱/手机号验证码登录，注册可选择仅邮箱、仅手机号、两者任选或同时验证。短信渠道支持阿里云、腾讯云与互亿无线、按场景配置模板、启停、测试发送及脱敏记录；需先启用对应短信插件。互亿无线填写 APIID/APIKEY 与已审核模板 ID，按模板顺序配置验证码和有效分钟变量。已有密码登录与邮箱流程继续可用，手机号注册无需填写邮箱，手机号仅支持中国大陆 `+86`。用户管理显示手机号与验证状态并支持按手机号搜索。详见 [HTTP API 合同](/docs/backend/http-api)。

## 上游渠道同步管理

后台「渠道同步」按每个系统渠道管理授权目录监控或模型广场价格同步脚本，每 30 分钟在北京时间整点和半点自动执行，支持暂停、立即同步和执行记录。价格更新保留每个价格档现有利润比例；授权与报价恢复后自动启用配置完整的已有型号，授权或对应规格报价消失时停用，记录分别显示启用与停用数量。未配置完整的新型号保持停用，网络异常或计费歧义不覆盖原配置。任务由服务端 Worker 与数据库租约协调，浏览器关闭仍可运行。详见 [上游渠道同步管理](/docs/backend/channel-sync)。

## 玉玺盒子 YX 视频

`yuxibox-video` 声明式插件支持 Seedance 2.0、2.5 及 2.5 按次型号。使用 JSON 创建任务、查询进度和鉴权下载视频，支持图片、视频与音频参考；自动比例映射为上游 `adaptive`。渠道按模型保存时长、参考数量与固定 720p 能力限制，执行仍使用该渠道保存的地址和凭证。插件可在线安装启用，完整字段合同见包内 `docs/interface.md` 与 [供应商文档](https://yuxibox.cn/docs)。

## 卓越剧场

工作区侧边栏提供「卓越剧场」入口。用户上传剪辑好的视频，填写标题、简介并可选上传图片封面后发布，所有登录用户都能浏览、搜索和播放。封面支持不超过 10MB 的 JPG、PNG、WebP，列表优先展示封面，未设置或加载失败时显示视频画面。作品页提供「全部作品」与「我的作品」筛选；只有上传者能够修改标题、简介、更换或移除封面以及下架自己的作品。

「上传短剧」支持一次选择多集视频，按文件名中的集数自然排序；作者可编辑每集标题、调整顺序、删除或追加集数，并标记连载或完结。每部短剧最多 200 集，支持竖屏封面与视频。观众可筛选短剧、选集、切换上一集/下一集及自动连播，重新打开时按账号恢复本机观看进度。分集发布与资源上传分开确认，失败重试保留本轮已完成上传，服务端校验作者归属与过期编辑。

上传复用账号资源存储、配额与大文件分片机制，显示上传和发布进度；只有视频资源与作品记录均保存成功才提示发布成功。发布失败可重试，已上传的视频不重复上传，同一资源不重复发布。下架撤销剧场访问，不立即删除仍可能被素材、项目或画布引用的视频；已发布的视频纳入资源引用与后台清理保护。页面支持简体中文、英语和明暗主题。

## 英语界面

创作首页、对话工作台主要操作、工作区导航与登录、注册、密码找回流程支持简体中文和英语切换。首次访问按浏览器首选语言选择，用户可以在账号菜单或登录页切换，选择保存在当前浏览器。英语模式会切换组件库语言、日期和数字格式，提供英文创作示例，并让 Excalidraw / tldraw 绘图工具使用内置英语。

非后台工作区进一步覆盖任务中心、积分弹窗、素材库、技能、插件及 Eagle、个人模型渠道、RunningHub 和 Agent 记忆。画布中的创建菜单、缩放、上传、拖放、素材选择、节点搜索、文本编辑和历史抽屉也可切换英语。分镜镜头语言选项只翻译显示文字，仍按既有字段值存储。用户填写的名称、提示词、技能内容、插件资料及后台配置的品牌文案和服务协议保持原文。其他画布深层工具仍有中文文案；管理员后台未纳入英语适配。短信验证目前仅支持中国大陆 `+86` 号码。

## 链动小铺外部充值入口

管理员可在「支付充值 → 支付渠道」表格中的链动小铺行配置 HTTPS 链接并启用入口；默认预填店铺地址，未启用时用户看不到。启用后积分中心出现独立店铺页签，在弹窗内嵌入网页，不将站内充值套餐当作店铺订单。店铺支付不创建站内订单，也不会自动到账，兑换方式由管理员另行确认。店铺能否被 iframe 嵌入及其风控验证由店铺自身决定，需真实浏览器验收。

## 卡藏 Midjourney

画布接收一次任务返回的全部图片，四张结果自动组成收起的图片堆叠，可展开、选择主图和分别使用。每张图保留独立资源及素材绑定，保存、刷新和任务重复同步不会将后续图片覆盖为第一张。已有仅显示首图的成功 Midjourney 节点在重新打开画布时从原任务恢复遗漏结果，无需再次生成。

`kacang-midjourney` 统一声明式插件提供 V6/V8 特惠、V7 特惠、稳定/高速三个生图协议。选择协议后自动填入供应商比例、默认比例、参考图上限和一次提交；禁用无合同的蒙版和通用输出参数。稳定版数值 quality 通过插件命名空间设置，不与宿主分辨率档混用。

特惠使用标准图片端点，稳定/高速使用受理和任务查询端点。结果支持顶层与 data 信封，全部单图及可选四宫格封面交给宿主立即保存；失败和空结果保留真实失败语义。完整模型和字段合同见插件包内 `docs/interface.md`。

## 沧元 Midjourney

`cangyuan-midjourney` 声明式插件分别提供 V7 与 1K/2K（供应商默认 V8.2）协议。V7 使用 `midjourney-v7`；1K/2K 使用 `midjourney-1k`、`midjourney-2k`，可在提示词显式写 `--v 8.2`。一次提交固定 `n=1`，全部结果交由宿主下载保存，参考图按供应商合同发送 HTTPS URL 字符串。

两条线路的参数、编辑端点和响应格式分别适配，不自动换模型。1K/2K 返回官网 CDN 原链，HTTP 403 会如实保留保存失败与原任务重试能力；插件不能消除供应商 CDN 的访问限制。完整字段与接口合同见插件包内 README 和 `docs/interface.md`。

创作页按整个任务一次消费返回图片，保留各图片的输出序号；一次请求返回多张时，素材与消息幂等去重不会再把后续结果当作第一张合并。

后台选择这两个协议时，“能力与参数”自动使用线路专属默认值：V7 为 4000 字符、五张参考图、不支持蒙版；V8.2 默认单张编辑源图、支持蒙版和十五种比例。两者默认自动尺寸、一次提交，关闭不支持的质量、透明背景、响应格式和输出格式选项。V8.2 在模型名未明确时暂用 1K，识别到上游 `midjourney-2k` 后改为 2K，切换档位保留管理员的参考限制、默认比例和价格。像素预设由宿主换算供页面展示，提交上游仍使用比例，实际尺寸由供应商决定。

## 自定义更新公告

## AutoDL 画面规格

## 云端 Agent（写入与生成仍待真实环境验收）

Agent 支持自动关联分镜资产：读取真实镜头行和当前画布素材后，按用户意图调用批量绑定工具，将角色、场景、道具、风格等引用写入对应行 `assetBindings`，供分镜资产列及后续生成参考使用。角色卡按实际角色资产及当前或固定版本解析形象引用，校验图片归属和就绪状态；不把角色卡当作普通文本或要求在卡片节点重复保存图片。每批最多 20 行，每行最多 16 项；通常合并保留旧绑定，显式替换可清空指定行。关联本身不生成媒体，也不覆盖关键帧或镜头提示词；遵守执行权限、快照、资源归属和节点锁定规则，保存后可撤销。

Agent 可将同一批互不依赖的图片、视频等素材并发生成，最多 4 个在途任务，空出名额后继续提交；实际执行数受 Worker、渠道及账号额度限制。自动执行在服务端准入后直接提交，请求审批逐项批准，只读不生成。依赖前项结果的生成和画布编辑保持顺序，单项失败不会自动重试收费任务，取消会收尾整批已提交任务。

浮窗支持移动、调整大小和浏览器偏好恢复；后端支持逐轮对话、可信历史、取消、Skills 快照、画布摘要/精读、审批后的画布写入及媒体生成。运行中可插话（下一步生效，不打断正在飞的调用）；多步任务可用 `plan_update` 维护待办清单并在输入框上方展示，未完成项会催办；`request_approval` 下首次 ≥2 项清单会先确认，`auto` 直接建立。`ask_user` 可弹出选项并结束本轮。个人记忆由 `remember_lesson` 写入待审，用户在「设置 → Agent 记忆」自己批准、添加、导出导入，并可用自己的文本模型手动或按日/周/月压缩相近条目。系统提示只带已批准记忆的索引（标题+适用场景），完整做法由 `recall_lessons` 按 topic/关键词取；管理员可按用户查看和删除，不能代批。只读模式不能写记忆。终态旧轮次按其冻结合同保留为不可变历史，新消息使用当前合同创建新轮，不篡改父运行；旧合同下仍活动或待审批的运行不会被新版服务恢复执行。执行权限仅支持只读、请求审批、自动执行；请求审批需独立批准收费生成，自动执行经服务端准入后在预算内直接提交图片 / 视频 / 音频生成。绝对权限已移除，浏览器旧选择重置为请求审批，历史保持原样。画布写入使用内容快照哈希；未开放外部 MCP。系统行为策略以版本化资源发布，用户/项目/画布可编辑常驻偏好；偏好正文固定在运行快照并按层只读，不整段塞入 system prompt，也不能提权或跳过审批。节点创建、更新字段、摘要投影和连线限制来自服务端能力 registry；能力卡同时描述用途、适用场景、不适用场景、维护代价和可用动作，由 Agent 结合镜头数量、连续性、逐镜审查和交接需求自主选择，不强制所有任务使用分镜。分镜脚本支持结构化创建、分页读取及按真实行 ID 追加、修改和删除；普通文本和 Markdown 不会被宣称为具备镜头级维护能力的分镜表。图片、视频和音频节点可安全修改标题与下一版提示词草稿，既有媒体、已提交提示词和任务状态不会被草稿编辑覆盖；媒体模型按生成模式和真实参考节点从统一目录筛选。审批和执行记录明确展示目标节点、类型、修改字段、名称变化及连线两端，前端不再依靠内部 ID 猜测；这些预览不替代服务端归属、快照、Capability、锁、预算与调用哈希校验。真实模型计费与浏览器联调仍待验收。

云端画布 Agent 已分离行为策略、用户目标、参考事实和运行状态。续聊保留已送达插话，不再继承代码预设的创作自由；旧待办只作上下文，可移除取消项，催办不会强制工具调用或无限重复。提示词来源与发布约束见[画布 Agent 提示词与用户意图](/docs/backend/agent-prompt-policy)，真实模型行为仍待场景验收。

## 3D 预演台（持续完善，待用户验收）

预演台从画布镜头节点打开，统一提供摆场、姿态、动画、摄影机与时间轴。镜头焦段和画幅共同决定取景，机位视图显示安全框；构图截图、白模视频、深度图与深度视频使用同一镜头摄影机输出。深度产物回写为独立画布节点，不自动作为普通图片参考提交给模型。

工作台内可下载当前模式的镜头截图、录制镜头画面，或通过浏览器共享选择器录制含面板与操作过程的窗口。实时镜头录制要求标签页保持可见。第二屏监看用独立窗口显示镜头画面，支持全屏；自动定位外接屏依赖浏览器授权，也可以手动拖动。工具条与帮助面板提供[预演台快捷键](/docs/canvas/canvas-shortcuts)。

画布 Agent 使用 `previs_scene_read` 读取摘要，使用 `previs_scene_create`、`previs_apply_patch` 经审批创建和修改场景。路径操作生成真实变换关键帧，设置路径替换对象原变换轨道，清除路径清空该轨道；焦段修改同步取景。`previs_preview` 仍依赖已打开的浏览器工作台执行，尚无完成回执。

演员使用本地打包的 CC0 光滑人体模型（Quaternius Universal Animation Library 的 Mannequin，许可见 `web/public/previs/LICENSE-mannequin.txt`），姿势与动作写在规范骨架上再重定向到蒙皮，存档与模型无关。落地规则在前端提交与 Agent 写入两侧一致：演员高度锁为地面，道具可抬高但底面不得低于地面，打开旧场景时自动拉回地下对象并提示。检查器按变换、体型、外观、姿态、动作分组，道具库为按比例缩略图卡片并可折叠。程序化布景、排戏和离线逐帧编码仍属后续工作。

## 技能库个人分类与画布 Agent 筛选

## 画布 operations 同步与本地恢复

画布内容按字段和对象生成 operations，节点、连线和顶层业务字段分别提交；平移、缩放等 viewport 只保存在本地。每次请求携带唯一 `mutationId` 和可选基线版本，服务端在同一事务中校验对象存在性、字段基线、资源归属并保存回执。可选顶层字段不存在时用 JSON `null` 表示，避免 `undefined` 被序列化为缺失属性。相同请求安全重放，响应丢失、断网、刷新或服务端暂时不可用时，浏览器保留已确认基线与未确认请求，后台使用原 ID 和原 payload 自动继续处理。结构化配额只聚合当前用户素材与画布数据，不扫描任务和 API 日志大字段，容量上限与事务语义不变。

不同字段的并发修改可以合并；同一字段或同一对象的基线不一致会返回冲突，当前本地修改继续保留。删除后的迟到节点、连线或媒体更新不会重新创建对象，只有显式新增 operation 可以创建实体。界面只显示同步状态，不提供版本记录、加载云端版、覆盖云端或手动恢复入口。

此合同不提供多人实时协同；它保证局部变更、幂等重放和删除保护，避免旧缓存静默覆盖新内容。内部历史表仍用于资源完整性维护和审计，不作为用户编辑入口。

相关实现见后端 [画布 operations 同步](/docs/backend/canvas-operations-sync)、`web/src/services/user-data-sync.ts`、`web/src/services/api/user-data.ts` 和 `web/src/pages/canvas/canvas-sync-status.tsx`。

## 画布智能引用

节点提示词面板提供“智能引用”入口，支持 AutoLink 开关和“一键引用全文”。输入已连接素材的名称、标签或素材栏序号后，按 Tab 或点击光标旁的候选项插入引用；全文引用会批量转换匹配到的指代，没有可转换内容时按钮禁用。

匹配仅覆盖当前已连接且激活的画布素材，跳过技能、素材库条目、重名歧义和已有引用。支持 `图1`、`图片1`、`image1`、`image 1` 及独立序号；普通数字文本如“约2秒”保持原样。AutoLink 默认在节点面板开启，开关为面板临时状态。

## 批量创作表

批量创作表每行是一项任务，每个参考图格子绑定一张图片；同一行可通过多个参考图列使用多张图。点击格子可选择画布图片或上传，也可把图片连线接到指定格子。已有图片替换前确认，清除格子保留源图片节点；保留列排序和表内跨行、跨列交换。

左侧 1、2 等列端口直接生效：一张图片供该列各行共用，多张图片按连接顺序分配。单格更换或清空后成为独立配置，不被列变化覆盖；“按列填充”可在确认后恢复已连接列的统一配置。列同步只更新参考图，不重建任务行；AI 文本列表创建的表格保留独立行、动态文本列和原有生成流程，未开放普通文本节点直接连入批量表。

顶栏、普通表头、行号和非交互留白均可拖动整表；输入框、参考格、按钮、列排序和原生滚动条保留各自操作。表内支持文字拖选、内部滚动、底部添加和在指定行下方插入。放大编辑与行内编辑使用同一份提示词。全局提示词非空时统一覆盖各行的生效提示词，清空后恢复各行原文；界面显示实际生效来源，Agent 的 `set_global_prompt` 和 `generationPreview` 沿用此规则。“批量换装”和“创意生图”的预设保留。

任务入队时保存提示词与参考资源快照，排队期间修改或旋转源图不会改变已提交的输入；旧结果在输入变化后标记“输入已变更”，由用户决定是否重新生成。超过 20 行时仅挂载可见行、附近行及正在编辑的行，减少大表 DOM 和重绘开销。最终浏览器联调与性能验收见[待测试](/docs/progress/pending-test)。

## 图片尺寸与方向

图片节点按原图比例确定显示尺寸，可用角点调整大小或打开图片预览。普通滚轮保留原画布操作；单选一张未锁定的普通图片后，按住 Ctrl 滚轮可等比例改变其显示尺寸，鼠标移到画布空白处仍作用于选中图片。连续滚动合并为一次撤销和保存，不重采样图片或改变生成参数。编辑框、表格内部、多选、锁定、图层图片和只读页不进行这种尺寸调整；触控板捏合仍操作画布。

在原图工具中选择“向左转 90°”或“向右转 90°”，首次会保留原图、自动创建已经旋转的编辑副本，并连接和选中它。副本顶部保留左右转按钮，之后在同一副本上继续旋转或恢复创建时的方向；也可提前用“创建编辑副本”。

旋转生成实际图片资源，副本的下载和新提交引用使用校正后的方向；原图及其既有引用保持原样。引用编辑副本的格子会随副本更新，已入队任务仍使用提交时的快照。原方向与已生成方向保留，重复切换可复用资源。锁定、只读或尚在上传的图片不能旋转；此入口不提供任意角度或镜像操作。节点工具组菜单使用统一宽高限制，长说明单行显示并保留完整悬停说明。

工具栏根据侧栏以外的实际可用宽度收起次要操作；节点编辑面板根据剩余高度调整位置或内部滚动，避免遮住底部控件。未选择显示模式时，窄于 1024px 的窗口默认使用专注模式；用户明确进入或退出后，窗口变化与刷新保留该选择。

## 提示词放大编辑

图片和视频节点的提示词面板支持放大编辑：窗口默认约 `min(1200px, 92vw)`，编辑区最小高度 200px，右下角可对角拖拽，方向键可微调。切换节点后尺寸恢复默认，节点上的紧凑面板外观不变。

## 系统渠道排序与前台别名

系统渠道模型选择器直接读取渠道下的模型列表：一级跨渠道按“模型展示名”分组并显示原色 Logo，二级显示该模型的“渠道展示名”及规格售价；留空使用所属渠道名称。模型调用标识不必相同，也不反查逻辑模型。系统渠道的“前台名称”已移除。调用保留用户选中的具体渠道，收起后显示“模型 · 渠道”，不因另一渠道更便宜而自动切换。图标优先使用图标库的原色版本，缺少彩色版本时使用单色版本；缺少配置时显示通用图标，不猜测产品品牌。

渠道模型价格档支持管理员单独配置积分成本价；后台请求记录同时显示销售金额和成本金额。成本按下单快照计算，不追随之后改价；普通用户页面及接口不返回成本字段。

系统渠道模型列表按规格显示成本价 / 销售价及利润率；文本输入、输出、缓存 Token 分开呈现。勾选多个模型可统一调价：弹窗一行一个模型，展示模型名、渠道展示名（上游 ID）、规格、成本与可编辑售价，多规格在模型行内纵向对齐。输入目标利润率并选择保留 0–6 位小数（默认 2 位），按 `成本 / (1 − 利润率)` 四舍五入实时计算；也可点击「重新计算」覆盖手动值，再逐项修改。保存最终输入售价，服务端校验价格与版本并原子保存，不改变成本或启停状态。

后台系统渠道通过“设置排序”、模型管理通过“自定义排序”打开完整列表。支持搜索选择条目后输入目标位置，也可拖动、上移和下移；列表显示从 1 开始的位置，点击“保存排序”统一生效，取消不会修改线上顺序。渠道行的“更多”菜单支持复制渠道，复制会生成独立的渠道、模型和价格档，并保留原连接配置与凭证。排序不受筛选及分页影响；并发修改会提示重新加载，避免覆盖其他管理员的调整。系统渠道模式下，用户端模型选择器沿用同一渠道及模型顺序。模型排序独立保存，不改变价格、能力版本或启用状态。

系统渠道可设置可选的前台别名；为空时显示渠道名，设置后公开目录和用户会话只返回别名，后台仍保留原名。别名最长 80 字，支持后台搜索。前台模型目录模式保留其独立配置。

注册默认每 IP 每小时允许 30 次注册请求、60 次验证码请求，单邮箱每小时另限 10 次且发送后间隔 60 秒。失败尝试也占请求额度，达到上限后的拒绝不会继续增加计数或延长窗口；限流响应携带真实剩余等待时间，注册页面显示倒计时并防止重复提交。已保存的运行策略仍需管理员按实际共用网络规模调整，不随默认值升级自动覆盖。

定时闲置资源清理与后台手动删除共同保护外观配置引用的浅色 Logo、深色 Logo、登录视频及封面；即使资源超过闲置期限也不会删除，外观配置无法读取时停止相关清理。

## 章节资产提取与任务浏览

画布视频支持鼠标悬停 350ms 后静音预览前 3 秒，不循环；全局仅一个悬停解码器，离开或操作画布立即停止并恢复封面。手动播放优先，系统开启减弱动态效果时不自动预览。

剧情章节支持一次提取角色、场景与道具，分别写入角色、环境和道具待确认资产。输出必须包含三类数组；无人章节可以只产生场景或道具，不把缺失字段当作提取成功。

场景和道具确认后保留描述与生图提示词，尚未出图时显示「待生成图片」。可使用项目画风生成参考图，或绑定素材库中已有图片；提取和确认不会自动发起收费生图。图片绑定创建新资产版本，已有镜头、画布继续引用原图片。生成任务的成功状态与图片绑定共同提交，取消或失去租约的任务不能换图；晚到图片不覆盖较新资产版本，原生成结果仍可在任务中心恢复使用。

任务详情只读取任务与日志，不因打开详情写入画布。视频任务列表和网格优先展示已有封面；没有封面时，在进入视口后提取首帧缩略图。后台请求明细默认仅显示请求，可切换仅下载或全部明细，导出沿用当前筛选条件。

## 站点及外观

管理员可以在“系统配置 → 站点及外观”统一管理品牌识别、登录页、SEO、首页收尾与备案、皮肤主题。品牌识别包括站点名、英文品牌标识、浅色与深色 Logo 和 Logo 外框；登录页包括主标题、说明、品牌视频和可选封面。Logo 可以只上传任意一套并自动复用，也可以分别适配浅色与深色界面；关闭外框后 Logo 会在原导航占位内等比放大。

前端入口在加载 React 应用之前先读取 `GET /api/public/appearance`。初始 HTML 不包含内置品牌名、Logo 或默认 favicon；只有公开配置成功或明确回退到内置外观后才渲染应用，避免自定义品牌访问时先闪现“影策”。自定义视频未设置封面时保持纯色背景直至视频首帧就绪，不复用内置视频封面。

浅色 Logo、深色 Logo、视频和封面通过后台专用上传接口进入现有资源存储，并由稳定的公开 slot URL 读取；公开响应不暴露资源 ID。正在使用的外观资源会阻止管理员从资源管理页直接删除。英文品牌标识可作为对象存储路径前缀建议，但不会自动覆盖已经保存的前缀或改写历史资源。“恢复影策默认”会恢复内置品牌值、SEO/页脚默认值、经典皮肤和默认 Logo 外框，同时保留已经上传的素材文件。

SEO 标题、描述、可选关键词会投影到浏览器 metadata、Open Graph、Twitter Card 与 canonical；版权信息在公共登录场景页脚显示。ICP备案默认关闭，启用后必须填写备案号，并链接至工信部备案系统。注册验证码与密码重置邮件的标题、正文和继承型发件人名称都会使用当前站点名。

皮肤主题以语义令牌集中管理浅色/深色背景、文字、表面、边界、主色、控件状态、hover/active/focus、图标、圆角、尺寸、动效和阴影。默认“经典黑白”不可修改或删除；“青瓷工作室”“暖柿纸境”“霓光紫境”作为重新校色的可编辑初始数据。每套主题还可独立设置警告色、危险操作常态/悬停/按下/前景，以及开关开/关轨道、悬停和滑块色。管理员可从经典或当前主题完整复制、新建、改名、编辑、启用和删除自定义主题；页面只消费语义变量，不按皮肤 ID 分叉业务组件。

主题卡顶部会按语义使用频次展示该主题浅色与深色令牌的全部去重颜色，宽度不足时保留高频色并截断尾部。颜色编辑器只在直接点击色块时打开系统取色器，点击名称、说明或 HEX 输入不会误触。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式 | 用途 |
| --- | --- |
| 扩展想法 | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。 |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。 |
| 强化风格 | 保留主体和动作，强化色彩、材质、光影与指定风格。 |
| 适配模型 | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考 | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。 |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

## 画布同步与离线恢复

## 画布外观

底部工具栏的“画布外观”面板支持浅色、深色、自定义三种主题，以及点阵、线稿、空白三种网格。浅色画布使用比白色节点更沉的中性雾灰背景，深色画布使用比原深色节点更亮的中性灰背景，让画布底层与内容表面保持稳定区分，同时避免蓝灰背景与黑色工具浮层产生色温割裂。

自定义主题会继承用户进入前的浅色或深色基础界面，并允许在“浅色界面”和“深色界面”之间切换。界面样式复用原项目整套节点、工具浮层、文字、边框和交互状态，不开放这些元素的任意改色；切换界面样式不会覆盖已经选择的画布背景和网格颜色。

自定义主题还允许调整画布背景色、背景明亮度、网格颜色和网格强度。颜色输入支持三位或六位 HEX，可带或不带 `#`；形成合法色码后实时写入当前画布，编辑过程中不会被父级状态覆盖，关闭外观面板也不会撤销。选择新的画布背景色时明亮度自动归零，确保画布首先精确显示输入色；之后仍可沿 OKLCH 亮度轴单独调整。不提供背景透明度，避免画布底色与底层颜色混合后产生偏色。“网格强度”使用 `0%` 最淡、`100%` 最明显的方向，避免“透明度”命名歧义。

自定义外观可以应用到当前画布，也可以保存为当前浏览器、当前账号 scope 下的新建画布默认值。当前画布外观沿用画布项目的既有持久化和同步流程；浏览器默认值不跨设备同步。

## 积分充值支付插件

内置提示词统一提供中文正文，详情阅读、复制、编辑和回填创作使用同一份中文内容。已有中文来源直接采用中文版本，其余外文正文翻译后随静态目录发布；模型名、引用标记和模板参数保留原有用途。来源及原页链接显示遵循后台来源展示开关。

译文维护在 `web/scripts/data/inspiration-prompts-zh.json`，记录原文 SHA-256；导入脚本写入目录前校验原文版本，缺译会停止导入。

外部提示词由 `web/scripts/import-inspirations.mjs` 同步。`web/public/inspirations/*.json` 继续提供静态目录数据，灵感大厅进入可视区域附近后才按需加载全量目录，浏览器缓存与会话内缓存避免重复请求；首页画廊池按创作类型限制为最多 48 条，封面保持稳定比例，非当前卡片使用懒加载，加载失败显示占位内容。

默认顺序在各外部来源内优先展示已有本地缩略图，减少首批分页对外站图片的依赖；未生成本地缩略图的条目仍保留。列表封面继续懒加载，打开详情后立即加载对应封面。

## 画布外观预设

顶部保留浅色、深色和自定义三个入口。浅深切换恢复该色调最近的预设或微调；自定义仅展开、收起当前色调的设置，切换浅深不会改变展开状态。浅色提供经典浅灰、粉色、米色、浅绿，深色提供经典深色和柔和深灰；可调整明亮度、网格强度，并在“更多颜色”中修改背景和网格颜色。

单个画布自动保存预设快照、浅深色各自的微调和网格样式，工作台主题切换不覆盖已有画布。未设置新画布默认时，新建画布随工作台明暗选择经典预设，并默认使用线网格；旧画布缺省仍按点网格处理，已有显式颜色和参数继续读取。“设为新画布默认”仅作用于当前账号与本浏览器。外观及添加节点面板限制高度并允许内部滚动。
